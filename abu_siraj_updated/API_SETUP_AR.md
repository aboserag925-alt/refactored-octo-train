# إعداد مفتاح API — شرح مبسط

## ما هو المفتاح؟
مفتاح API هو سرّ يسمح للخادم بإرسال طلبات إلى خدمة الذكاء الاصطناعي نيابة عن تطبيقك. عامله مثل كلمة مرور.

## الخطوات
1. افتح منصة المطورين الرسمية: https://platform.openai.com/
2. سجّل الدخول.
3. افتح إعدادات API keys وأنشئ مفتاحًا جديدًا للمشروع.
4. راجع إعدادات الفوترة وحدود الإنفاق قبل الاستخدام؛ فوترة API منفصلة عن اشتراك ChatGPT.
5. على الكمبيوتر، داخل مجلد المشروع، انسخ `.env.example` وسمّ النسخة `.env`.
6. افتح `.env` بمحرر نصوص، واستبدل النص بعد `OPENAI_API_KEY=` بالمفتاح الحقيقي.
7. احفظ الملف، ثم شغّل `npm start`.

مثال توضيحي فقط:
`OPENAI_API_KEY=ضع_المفتاح_الخاص_بك_هنا`

لا تستخدم المثال كمفتاح حقيقي، ولا تشارك مفتاحك في المحادثات أو الصور أو ملفات HTML. إذا ظهر المفتاح للآخرين، ألغِه وأنشئ مفتاحًا جديدًا.

## التكلفة
تُحسب تكلفة API حسب النموذج وحجم الإدخال والإخراج والأدوات المستخدمة. ابدأ باستخدام قليل، وضع حدود إنفاق وتنبيهات من لوحة المطورين. الأسعار تتغير؛ راجع صفحة الأسعار الرسمية:
https://developers.openai.com/api/docs/pricing

## لو أنت تستخدم الموبايل فقط
تقدر تعدّل ملفات المشروع من الموبايل، لكن تشغيل خادم Node.js واستضافته بشكل دائم أسهل عادةً من كمبيوتر أو خدمة استضافة. لا تضع المفتاح في واجهة المتصفح حتى لو كانت خاصة.
