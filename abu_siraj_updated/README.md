# أبو سراج — V2.1 (إيجنت بأدوات + جيميل)

مش شات بوت: بيخطط وينفّذ بنفسه في حلقة (حتى `MAX_STEPS` خطوات)، ويستخدم أدوات حقيقية، وأي إجراء يغيّر حاجة بيستنى موافقتك بزر. **بدون مكتبات** — Node.js 20+ بس.

## التشغيل
1. انسخ `.env.example` إلى `.env` واكتب `OPENAI_API_KEY` (الشرح في `API_SETUP_AR.md`) و`ACCESS_PASSWORD`.
2. `npm start` ثم افتح `http://localhost:3000`.

## الأدوات
| الأداة | الصلاحية |
|---|---|
| بحث ويب | مباشر (قراءة) |
| `fetch_url` قراءة صفحة | مباشر، ومحجوب عليها العناوين الداخلية |
| `list_files` / `read_file` | مباشر، داخل `workspace/` فقط |
| `write_file` | **بموافقتك** (تشوف المسار والمحتوى) |
| `remember` / `recall` / `forget` | مباشر، ذاكرة طويلة في `data/notes.json` |
| `run_command` | **بموافقتك**، ومعطّلة حتى تكتب `ENABLE_SHELL=1` |
| `gmail_search` / `gmail_read` | مباشر، **قراءة فقط**، بعد ربط جيميل (شوف `GMAIL_SETUP_AR.md`) |

## الحماية
تسجيل دخول بكوكي موقّع، 5 محاولات دخول/15 دقيقة، 15 رسالة/دقيقة، حد يومي لطلبات النموذج `DAILY_LIMIT`، الخادم على `127.0.0.1` افتراضيًا، والمفتاح على الخادم فقط.

## حماية الإيميلات
- الدخول بتسجيل جوجل الرسمي (OAuth)، من غير كلمة سر، والمفتاح بيتخزن في `data/google.json` بصلاحية مقصورة عليك.
- نص الإيميل بيتعامل كبيانات مش تعليمات، وبعد قراءة أي إيميل فتح أي رابط (`fetch_url`) بيحتاج موافقتك عشان إيميل مفخخ ميسرّبش بياناتك. بحث الويب المدمج مش تحت سيطرة الخادم، فلو شاكك في إيميل اضغط "محادثة جديدة".
- على الاستضافة: اكتب `PUBLIC_URL` بـ https و`TRUST_PROXY=1`، وسيب `ENABLE_SHELL=0`.

## تنبيهات
- `run_command` يشغّل أوامر على جهازك بنفس صلاحياتك، ويقدر يقرأ ملف `.env`. فعّله فقط لو بتقرأ كل أمر قبل الموافقة، وعلى جهاز مش مكشوف على الإنترنت.
- الملاحظات المحفوظة بتتحط في تعليمات النموذج كبيانات. راجع `data/notes.json` من وقت للتاني.
- للموبايل خارج البيت: استضافة HTTPS فقط.

## مش موجود بعد
تطبيق أندرويد للتحكم في الهاتف، إرسال إيميل (القراءة فقط حالياً)، ربط تيليجرام (فيسبوك مقفول بواجهة رسمية)، ومهام مجدولة تشتغل لوحدها.
