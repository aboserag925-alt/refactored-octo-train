# أبو سراج AI — واجهة ويب عربية

## تشغيل محلي على Termux
1. فك ضغط الأرشيف في مجلد على الهاتف.
2. افتح Termux وانتقل إلى المجلد الذي يحتوي `app.py`.
3. ثبّت المتطلبات:
   ```bash
   pkg update
   pkg install python -y
   pip install -r requirements.txt
   ```
4. اضبط مفتاح OpenAI محلياً في جلسة Termux (لا ترسله في المحادثة ولا تضعه في ملف):
   ```bash
   export OPENAI_API_KEY='ضع_مفتاحك_محلياً_هنا'
   ```
   استبدل النص بمفتاحك محلياً. إذا لم يكن لديك مفتاح، أنشئه من لوحة OpenAI الرسمية وتحقق من حدود الاستخدام والفوترة.
5. شغّل:
   ```bash
   python app.py
   ```
6. افتح متصفح الهاتف على `http://127.0.0.1:5000`.

## من جهاز آخر على نفس Wi-Fi (اختياري)
هذا يفتح الخادم على الشبكة المحلية وقد يعرّضه لأشخاص آخرين عليها. لا تستخدمه على شبكة عامة ولا تفتح منفذ الراوتر للإنترنت:
```bash
export SERAG_HOST=0.0.0.0
python app.py
```
ثم افتح `http://IP-الهاتف:5000` من الجهاز الآخر. استخدم عنوان IP المحلي للهاتف.

## النشر كموقع عام
هذه النسخة للاختبار المحلي فقط. لا تنشر خادم التطوير مباشرة على الإنترنت. قبل النشر أضف HTTPS، تسجيل دخول ومصادقة، تحديد معدل الطلبات، وسياسة خصوصية. خزّن `OPENAI_API_KEY` و`SESSION_SECRET` في لوحة الأسرار بمنصة الاستضافة، لا في ملفات المشروع.

## المتغيرات
`OPENAI_API_KEY` مطلوب. `OPENAI_MODEL` اختياري (الافتراضي `gpt-4.1-mini`)، و`PORT` اختياري (الافتراضي 5000)، و`SERAG_HOST` افتراضياً `127.0.0.1`.
الذاكرة والمهام والملاحظات تحفظ محلياً في `serag_agent_data/`.
